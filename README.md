# coamas-action-intent-schema
Canonical JSON Schema (draft/2020-12) for the Action Intent — the universal cross-domain artifact of the COA-MAS governance meta-framework. The Action Intent is the standardized, cryptographically signed declaration that any domain can read and evaluate by its own sovereign criteria.

Supplementary artifact to: COA-MAS v2 — A Meta-Framework for Cross-Domain Multi-Agent Governance (Working Paper v0.3).

Extends: COA-MAS v1 — doi.org/10.5281/zenodo.19057202
